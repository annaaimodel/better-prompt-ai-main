# Cadence — Competitive Position & Monetization (Business Case)

> Saved from the deep-dive research. Honest, not promotional — includes the bear
> case. Sources were largely search-snippet + press-release level (most vendor
> pages block automated fetch), so treat figures as directional.

## 1. The competitive gap (verified)

**Real-time live-call copilots exist** (Attention, Aircover, Winn.ai, Balto,
Cresta, Convin, Pifini, Suade) and **white-label "bring-your-own-method" tools
exist** (Rocky.ai, SalesAsk, Hyperbound, Quantified) — but they don't overlap:

- **Real-time + custom *methodology*** is partly done: **Winn.ai** reinforces 20+
  named methodologies (MEDDIC, SPIN…) live (Deel reported +33% win rate);
  **Cresta** can encode proprietary behaviours into live cues. So "real-time +
  a method" is **not** virgin territory.
- BUT those tools (a) reinforce **structured B2B qualification checklists**, not a
  **consultative closing *psychology*** (gospel-vs-garbage, Six Masks, belief
  diagnosis); (b) are **enterprise / contact-center priced**; (c) are **not
  white-label for a community to load its own method.**
- The white-label + custom-method tools (Rocky.ai, SalesAsk, Hyperbound) are
  **roleplay / post-call**, not live.

**The empty box (our position):** a **white-label, real-time copilot that runs
each community's own consultative method** (Dojo for us, NEPQ / Closer Cartel /
etc. for others), priced for **solo high-ticket closers and coaching
communities** — the segment the enterprise tools structurally ignore. No product
found unites real-time + member-facing white-label + bring-your-own-methodology.

**Caveats:** Winn.ai proves the live-method concept has value *and* that an
incumbent could extend toward white-label. Live-cue tech is commoditizing
(Zoom AI Companion bundles real-time free; Otter/Fireflies shipped live assist),
so the moat is **niche + method-type + white-label + integration**, not the tech.

## 2. The niche has money

- Closers.io ~$15M ARR (est.); closing courses $2.5k–$8.4k; communities $27–$40/mo.
- Closers earn ~$110k/yr median on ~10% of $3k–$50k deals → one extra deal is
  worth far more than any per-seat price (huge value headroom).
- A few AI tools already target closers (GradeMyClose, Closr, CloserCoach) but
  they're **post-call graders / roleplay**, mostly freemium.

## 3. White-label pricing to a community

Value headroom is large; the constraint is the **owner's** pricing model.

| Model | Realistic number | When to use |
|---|---|---|
| One-time white-label **setup** | **$1,500–$3,000** | Always — load + brand + onboard their method. Filters tire-kickers. |
| **Flat platform license** (by member band) | ~$1,500/mo (≤300) → $2,500–3,000 (≤500) → custom | Best *first* deals — easy yes, no per-seat admin |
| **Per active seat** (wholesale) | $20–$40/seat/mo (~$25 sweet spot) | At scale / once trust built (300 active ≈ $7.5k/mo) |
| Optional **rev-share** | 30–40% if owner upsells members | Lower-commitment alternative |

- **Realistic first deal:** ~$1.5k–$3k/mo + setup; scales to $5k–$10k/mo for a
  large active community on per-seat.
- **Cost floor:** ~$1–3/call (STT + LLM) → healthy margins.
- Comps: Winn.ai ~$69/seat, Hyperbound $150–250/seat, Rocky.ai white-label ~$10/seat.

## 4. How to pitch a community owner

**Positioning (one line):** *"I'll clone your coaching into every member's ear —
live, on their real calls, branded as yours."* It productises the guru's
expertise and scales it 24/7. It's a **retention + differentiation** play, not a
cost (members who get results don't churn → easier sales for the owner).

**The pitch (run it the Dojo way — lead with their world, show don't tell):**
1. Open on their pain, ask: what % of members actually get the result? what's
   that doing to churn / refunds?
2. **Show, don't tell:** a 10-min **live demo with *their* method loaded**, on a
   mock call. This is what sells it.
3. Frame as **their asset** — white-label strengthens their brand; they'd be
   first in their space (no competitor offers this combo).
4. **De-risk:** pilot one cohort, proof-before-payment / performance-tied trial;
   you do all setup (zero build for them).
5. Simple commercials: setup + monthly, done-for-you.

**Sequencing:** start with ONE warm community → pilot → results case study →
then approach bigger gurus with proof. Don't cold-pitch a big name first.

## 5. Realistic verdict

- Generic copilot to get rich: **no** (crowded, commoditizing, free incumbents;
  median micro-SaaS ≈ $500/mo, ~18% reach $1–5k MRR, 12–18 months to $1k MRR).
- Niche + method-true + white-label, distributed via communities: **a credible
  modest business** — $1–5k MRR in 12–18 months is the realistic "good" outcome,
  with volatile upside beyond, *if* sold through community/course partnerships.
- **Strongest reason regardless:** build it for **yourself** — one extra
  $3k–$50k close at 10% pays for it many times over, independent of ever selling
  it. Selling is optional upside; your own use is the guaranteed ROI.
