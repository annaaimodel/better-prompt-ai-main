Lite mode

A focused, call-first setup. Hides Today, Pipeline, Add lead, Coach and Content, leaving Live, Knowledge, Meds, Playbook, Assets and Settings. Your data is untouched, this only changes which tabs show. Only an admin access code can turn this off.

Cross-device sync

Keep your leads, playbook, products and everything else in step across your phone and laptop. Pulls the latest when this device opens and saves automatically as you work. Same access code on each device = same data.

First time on a new device: tick the box, then if your data does not appear use Pull cloud → this device. To make the cloud match the device you trust, use Push this device → cloud there.
